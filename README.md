# 🛒 SCVSupermercado

Sistema backend para gestión y control de ventas de supermercado desarrollado con Java y Spring Boot.

El proyecto permite administrar productos, ventas, sucursales y operaciones comerciales utilizando arquitectura backend moderna y persistencia relacional.

---

# 🚀 Objetivo

Desarrollar una base backend orientada a sistemas ecommerce y gestión comercial, aplicando buenas prácticas de arquitectura, APIs REST y organización modular.

---

# 🛠 Tecnologías utilizadas

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Docker
- Docker Compose
- Lombok

---

# ✨ Características principales

- Gestión de productos
- Gestión de ventas
- Administración de sucursales
- Persistencia relacional
- API REST
- Arquitectura backend modular
- Contenedorización con Docker

---

# 📚 Arquitectura

El proyecto sigue una estructura organizada por capas para separar lógica de negocio, persistencia y controladores, facilitando mantenimiento y escalabilidad.

---

# ⚙️ Ejecución

```bash
docker-compose up --build
```
